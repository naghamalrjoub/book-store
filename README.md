# Book Store App

A small e-commerce style web app that fetches books from an external API and allows users to add them to a cart with quantity tracking and total price calculation.

## Features
- Fetch API integration
- Dynamic DOM rendering
- Add to cart with duplicate prevention
- Cart total calculation
- Responsive Bootstrap layout

## Tech
HTML, CSS, Bootstrap, JavaScript (ES6)

## API used
Data fetched from: https://api.itbook.store/1.0/search/mongodb
